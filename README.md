# BlackSoulsMusic
Black Souls Music - a custom high-quality soundtrack replacement for your boss battles, biomes, and events! This is my first mod, so any feedback and support are greatly appreciated.

This version completely overrides the music for all Pre-Hardmode, Hardmode bosses, Post-Moon Lord encounters, and key surface biomes. The mod is highly adaptive, meaning it works perfectly in plain vanilla Terraria as well as alongside Fargo's Souls Mod. Our custom low-level audio override logic ensures other music mods won't mute your custom tracks.

⚠️ IMPORTANT NOTE:
If you are running Fargo's Souls Mod, please make sure you also have the official Fargo's Music Mod enabled. This is strictly required for proper audio layering and mixing!

⚙️ Current Features (v2.1):
  Complete soundtrack overhaul for all Pre-Hardmode, Hardmode, and Post-Moon Lord bosses.
  Advanced adaptive audio system for Mutant: different music tracks for Phase 2 and Phase 3 depending on your world difficulty (Eternity / Masochist / Legendary Masochist).
  Custom atmosphere music tracks for key surface biomes (Forest Day/Night, Town Day/Night, Space, Desert, Snow, Ocean Day/Night, Mushroom, Graveyard).
  Custom music overrides for 10+ global events and invasions (Blood Moon, Solar Eclipse, Goblin Army, Pirates, Martians, Pillars, etc.).
  Brand new custom animated Main Menu theme inspired by Black Souls II (with background art and floating particles).
  Improved in-game configuration menu (fully English-localized, with clean design).
  Unique setting slider for Deviantt, allowing you to choose between Elizabeth 3 and Gokumashin themes.
  Stable and optimized code structure with smart master switch toggle.
